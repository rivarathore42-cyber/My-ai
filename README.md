# Galaxy AI Engine v7.0

A private assistant: 20 agents (math, knowledge, code, creative writing, translation, data, memory, voice and more),
one chat page with a voice orb, and paired access. This repository deploys to Render.com as a Docker web service.

## Deploy on Render (one-time setup)

1. Push this repository to GitHub.
2. In Render, choose **New > Blueprint** and select the repository. Render reads `render.yaml` and builds the `Dockerfile`.
3. When the service is live, open its **Logs** and find the line that starts with `PAIRING CODE:`.
4. Open the service URL and enter that code. The browser keeps a private session for 30 days.

Render sets `$PORT`; the server listens on it on all interfaces. The health check is `/health`.

## Read before relying on the free plan

- A free instance has limited memory (check Render's current plan list) and sleeps when idle. The first request after a
  sleep is slow.
- A free instance has no persistent disk. A restart or a sleep clears the database, so conversations, memory and paired
  devices are lost. Pair again after each wake-up; the new code is in the logs.
- The local model is off by default (`GALAXY_SKIP_LLM=1`). The engine then runs in heuristics mode, and all 20 agents
  still answer, with a plain reason whenever they cannot. A model needs more memory than a free instance has.
- Hosting terms (payment requirements, limits) change. Check the Render dashboard before you rely on them.

## Settings

| Name | Default | What it does |
|---|---|---|
| `GALAXY_AUTH` | `paired` | Keep `paired` on a public service. `local` is refused on any non-loopback address. |
| `GALAXY_OWNER_ID` | `owner` | The user id a paired device belongs to. |
| `GALAXY_API_TOKEN` | generated by Render | The operator token for admin routes. Chatting never needs it. |
| `GALAXY_SKIP_LLM` | `1` | `1` runs heuristics only; `0` loads the local model (needs a build with `INSTALL_LLM=1`). |

## Run locally

```
pip install -r requirements.txt
python run.py
```

Open http://127.0.0.1:8000/ and enter the pairing code the console prints.

## Voice (Hey Galaxy)

Voice Wake-Up runs offline in the browser with Vosk. It needs `vendor/vosk.js` and two model archives, fetched at build time
only when you set the build argument `FETCH_VOICE=1`. Check the sources in `scripts/fetch_voice_assets.py` first. Without
them, the page shows voice as unavailable and nothing else changes. Audio never leaves the device.

## Other hosts

`deploy/huggingface/` holds the Hugging Face Spaces variant. Hugging Face needs its Dockerfile at the repository root, so
copy `deploy/huggingface/Dockerfile` and `deploy/huggingface/README.md` to the root before you use it there.
